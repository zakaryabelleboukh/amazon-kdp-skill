# Example: Children's Book Workflow

## Prompt

```text
Create a production plan for a children's picture/activity book for ages 6–8.

Define:
- learning or entertainment goal
- page-by-page structure
- age-appropriate language guidance
- illustration direction
- cover brief
- interior layout considerations
- metadata draft
- pre-publication QA checklist

Do not use copyrighted characters or imitate a living artist's distinctive style.
Flag any age-rating or platform requirement that needs current verification.
```

The workflow should prioritize age-appropriate language, pacing, readability,
visual planning and consistency.
