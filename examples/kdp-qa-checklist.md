# KDP Pre-Publication QA Checklist

## Manuscript
- [ ] Complete manuscript
- [ ] Correct chapter order
- [ ] No missing sections
- [ ] Spelling and grammar reviewed
- [ ] Terminology consistent

## Front matter
- [ ] Title page
- [ ] Copyright page where appropriate
- [ ] Table of contents where appropriate
- [ ] Other required preliminary pages checked

## Interior
- [ ] Correct trim size selected
- [ ] Margins checked
- [ ] Bleed checked where applicable
- [ ] Page numbers consistent
- [ ] Headers/footers consistent
- [ ] Typography consistent
- [ ] Images correctly placed
- [ ] No unintended clipping or overflow
- [ ] Empty pages reviewed

## Metadata
- [ ] Title matches manuscript/cover
- [ ] Subtitle matches manuscript/cover
- [ ] Description accurately represents the book
- [ ] Keywords are relevant and non-spammy
- [ ] Categories accurately represent the book
- [ ] Audience/age information is appropriate

## Cover
- [ ] Front cover text is accurate
- [ ] Author name is consistent
- [ ] Spine/back requirements checked when applicable
- [ ] Dimensions/bleed verified for the selected format
- [ ] Images have appropriate rights

## Final verification
- [ ] Exported files open correctly
- [ ] Final files visually inspected
- [ ] Current official KDP requirements checked
- [ ] No unsupported guarantees or fabricated claims
